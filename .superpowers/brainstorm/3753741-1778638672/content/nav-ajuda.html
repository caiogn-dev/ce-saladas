Como melhorar a navegação do cardápio para usuários 30+?

Foco: clareza imediata — a pessoa precisa saber onde está, o que tem e como chegar lá sem pensar

A — Chips com emoji + barra de contexto

Cada categoria ganha um ícone visual. Uma barra fina acima indica "você está em: Saladas". Primeira visita: hint animado "use as abas abaixo para navegar".

A favor

  • Emojis identificam categoria de relance — sem ler
  • Indicador "você está em" elimina dúvida de localização
  • Hint desaparece após 1 visita — não polui retornos
  • Mudança mínima no código — só adicionar ícone + indicador

Contra

  • Chips ficam um pouco maiores (mais altura)

B — Banners de entrada por seção

Cada seção começa com um banner visual (ícone grande + título + subtítulo explicativo). Quem não sabe o que é "Monte sua Salada" lê na hora.

  • Explica cada seção on-the-fly conforme o usuário rola

C — Combinação: chips com emoji + banner só no "Monte sua Salada"

Emojis em todos os chips. Banner explicativo apenas na seção complexa ("Monte sua Salada"). Outras seções sem banner — mantém fluência.
